# Что за E?

Статический справочник пищевых E-добавок на SvelteKit. Каталог содержит действующие и исторические коды, редакционную оценку риска и раздельные статусы для ЕС и ЕАЭС.

## Разработка

```sh
npm install
npm run dev
```

## Данные

Исходный экспорт разговора не хранится в репозитории. Чтобы повторить извлечение и пересборку каталога:

```sh
npm run data:extract -- /path/to/what-e.json
npm run data:build
```

`data:build` использует исторический индекс E-номеров как вторичный источник названий и сопоставляет коды с официальным текстом ТР ТС 029/2012. Отсутствие автоматического совпадения сохраняется как неизвестный статус, а не как запрет.

## Проверка

```sh
npm run check
npm run lint
npm run test:unit -- --run
npm run test:e2e
npm run build
```

## Vercel

Проект использует `@sveltejs/adapter-vercel`. Все 525 страниц добавок пререндерятся. Для корректного `sitemap.xml` задайте `PUBLIC_SITE_URL` с публичным адресом сайта; без переменной используется `https://what-e.vercel.app`.
