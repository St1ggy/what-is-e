# Что за E?

Статический справочник пищевых E-добавок на SvelteKit. Каталог содержит действующие и исторические коды, редакционную оценку риска и раздельные статусы для ЕС и ЕАЭС.

## Разработка

Проект использует Bun 1.4.0. Версия закреплена в `package.json`; чтобы установить её глобально через mise:

```sh
mise use -g bun@1.4.0
```

```sh
bun install
bun run dev
```

## Данные

Оценки 315 кодов хранятся в `data/official-assessments.json`. Это редакционные переводы выводов из конкретных заключений EFSA и записей JECFA; неоднозначные совпадения остаются без оценки. Снимок разрешённых кодов ЕС хранится в `data/eu-authorized-additives.json`.

```sh
bun run data:build
```

`data:build` использует исторический индекс E-номеров только как вторичный источник названий, добавляет официальные оценки EFSA/JECFA, сверяет статус ЕС с Food Additives Database и сопоставляет коды с официальным текстом ТР ТС 029/2012. Отсутствие автоматического совпадения сохраняется как неизвестный статус, а не как запрет.

Runtime-код получает каталог через async-контракт `src/lib/server/additive-repo.ts`. Сейчас репозиторий читает локальный `additives.json`; для перехода на backend достаточно заменить реализацию `AdditiveRepo`, не меняя страницы и UI. Поскольку маршруты пререндерятся, данные фиксируются на момент сборки.

## Vercel

Проект использует `@sveltejs/adapter-vercel`. Все 525 страниц добавок пререндерятся. Для корректного `sitemap.xml` задайте `PUBLIC_SITE_URL` с публичным адресом сайта; без переменной используется `https://what-is-e.vercel.app`.
